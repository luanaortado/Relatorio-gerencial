# Relatório Gerencial BR Mobility

Dashboard gerencial mensal da BR Mobility, consolidando indicadores operacionais, comerciais, de produtividade e financeiros.

## Versão atual

- Período consolidado: janeiro a setembro de 2026
- Arquivo principal: `index.html`

## Como visualizar

Baixe o repositório e abra o arquivo `index.html` em um navegador moderno. O dashboard é autocontido e pode ser consultado localmente.

## Atualizações mensais

A cada fechamento, substitua o `index.html` pela versão validada do mês e registre a alteração no histórico do GitHub.
